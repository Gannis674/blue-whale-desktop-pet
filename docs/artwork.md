# 角色与素材

这是围绕中文社区“DeepSeek 蓝色大肥鱼／鲸鱼娘”形象制作的非官方同人桌宠。
仓库使用的 PNG 为开发过程中使用内置 imagegen、参考角色图片重新生成的素材，程序用这些图片进行分层动画和方向切换。

| 文件 | 用途 |
| --- | --- |
| `turnaround.png` | 正面、侧面、背面和腿部，供行走与转身使用 |
| `parts.png` | 身体部件、普通表情和墨镜表情 |
| `back_hair.png` | 后发层 |
| `hungry.png` | 哭哭讨饭 |
| `states.png` | 喂饭状态 |

方向素材的生成提示词见 [turnaround-prompt.txt](turnaround-prompt.txt)。用户提供的原始参考图、视频和聊天记录未包含在仓库中。
项目并非 DeepSeek 官方产品。代码的许可选择和角色美术的权利说明应分别记录；本次整理尚未替作者指定开源许可证。
